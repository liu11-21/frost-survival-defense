# Third-Party and Generated-Asset Provenance

This file records known provenance relevant to public redistribution. It is an inventory, not a substitute for upstream license texts or legal advice.

## MakeHuman / MPFB

The character-authoring pipeline uses MakeHuman/MPFB-derived human assets.

MakeHuman Community documents:

- MakeHuman/MPFB **core graphical assets** as CC0;
- exported models made from those core assets as freely usable, including commercially;
- MPFB program source separately under GPL and MakeHuman program source separately under AGPL.

This repository uses the graphical/export pipeline; it does not treat the MPFB/MakeHuman software license as the license for exported character assets.

Important: separately downloaded MakeHuman community assets can have different licenses, including CC-BY. Any such asset added in the future must be recorded individually here with author/source/license.

Upstream project family: `makehumancommunity` / MPFB.

## Google Gemini-generated music

The BGM files under `public/assets/audio/music/` were generated by the project owner using **Google Gemini**.

Current committed tracks include:

- `menu-idle.mp3`
- `preparation.mp3`
- `combat.mp3`
- `intense.mp3`
- `warning.mp3`
- `wave-clear.mp3`

Google's current general Terms of Service state that Google does not claim ownership over original content generated by services that support generation. Those terms also require users to respect third-party intellectual-property and other legal rights.

Accordingly:

- these audio files are **not** licensed under this repository's Apache-2.0 software license;
- the project does not represent them as exclusive human-authored copyrighted works;
- public availability in this repository is for the project/runtime and contribution workflow and does not create a separate open-source audio license;
- downstream users remain responsible for applicable law and the Google terms relevant to their use.

Generation prompts/account-private data are intentionally not committed. Project-level provenance is retained here so the binary files are not source-less.

## npm dependencies

JavaScript dependencies are declared in `package.json` / `package-lock.json`. Their upstream licenses remain their own and are not replaced by this project's Apache-2.0 code license.

Direct dependencies currently include Babylon.js packages; development dependencies include Playwright, TypeScript, Vite, and Node.js type definitions. Refer to each distributed package's license metadata for the authoritative terms.

## Contribution rule

Any future third-party model, texture, font, audio file, code sample, dataset, or generated asset must add its source and redistribution license/provenance in the same pull request. Do not merge an asset whose redistribution status is unknown.
