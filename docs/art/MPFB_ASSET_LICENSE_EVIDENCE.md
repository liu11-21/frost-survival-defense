# MPFB / MakeHuman asset licence evidence

Retrieved **2026-08-07**. Official MakeHuman Community sources only — the
project website and the `makehumancommunity` GitHub organization. No
third-party mirrors, no search-engine results.

## Position

| What | Licence |
|---|---|
| **MPFB add-on code** | `GPL-3.0-or-later` — per the extensions.blender.org catalogue entry, the package `blender_manifest.toml`, and `LICENSE.CODE.md` in the official repository |
| **Bundled core graphical assets** (base mesh, targets, rigs, skins, UV layers, textures) | **CC0 1.0 Universal** — per `LICENSE.ASSETS.md` in the official repository |
| **Third-party contributed assets** | **None used.** Nothing outside the assets bundled in the official MPFB extension has been installed or referenced. |

### The separation that matters

The add-on's GPL applies to MPFB's **code**, which runs inside Blender at
authoring time. It is a build-time tool, exactly like Blender itself.

**No MPFB code is packaged into the game runtime.** The game ships only the
exported model — geometry, weights and textures derived from the CC0 core
assets. `scripts/blender/` is authoring tooling and is not bundled by Vite
into `dist/`; the runtime loads `.glb` files and nothing else.

This is the same relationship the project already has with Blender: a
GPL/GPL-compatible tool produces an asset, and the asset is not a derivative
work of the tool's source.

## Installed package cross-check

From `scripts/blender/mpfb_probe.py`, run against the actual installation:

```
package    %APPDATA%\Blender Foundation\Blender\5.2\extensions\blender_org\mpfb
id         mpfb          version 2.0.17        build 20260722
manifest   license = ["SPDX:GPL-3.0-or-later"]
assets     targets 1445 · rigs 18 · uv_layers 13 · textures 12
           mesh_metadata 6 · poses 5 · node_trees 3 · 3dobjs 1 · expressions 1
```

The four `license.json` files inside the package are MakeClothes / MakeSkin /
MakeExpression **asset-authoring templates** — metadata written into assets a
user creates. They are not the package's asset grant, which is why the
repository's `LICENSE.ASSETS.md` was needed.

## What is deliberately not committed

The MPFB extension directory, its cache, the downloaded archive, the system
asset directories and Blender user preferences are all excluded. Only the
licence texts above are versioned, under `third-party-notices/mpfb/`.
