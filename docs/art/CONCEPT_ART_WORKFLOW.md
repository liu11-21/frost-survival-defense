# Concept-art workflow

1. Create a silhouette sheet with front, side, back and 45-degree views.
2. Mark gameplay scale beside a 1.9 m hero and a 4.2 m gate opening.
3. Resolve color/material questions in the sheet before modeling; the Blender
   file remains the source of truth for the shipped look.
4. Keep references in `assets-source/concept-art/`; do not load them in the
   browser bundle. Record any external source and license first.

Use `CONCEPT_PROMPT_TEMPLATE.md` when generating a non-shipping mood or shape
reference. The prompt is a design aid, not a replacement for a licensed asset.
